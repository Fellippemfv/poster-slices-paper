# PosterSlice 🎨🖼️

**PosterSlice** é uma ferramenta web simples e poderosa projetada para transformar qualquer imagem em um pôster gigante, fatiando-a automaticamente em várias folhas A4 prontas para impressão.

## 🏫 Ideal para Escolas e Trabalhos Acadêmicos
Esta aplicação foi desenvolvida pensando em facilitar a vida de estudantes e professores. É a solução perfeita para:
- Criação de murais escolares.
- Cartazes para feiras de ciências.
- Decoração de salas de aula.
- Projetos artísticos em grupo.

Com o PosterSlice, você não precisa mais se preocupar em como ampliar uma imagem manualmente. O site faz todo o trabalho pesado de redimensionamento e divisão para você!

## ✨ Como Funciona?
1. **Upload da Imagem:** Escolha sua foto (JPG ou PNG) de alta qualidade.
2. **Configuração da Grade:** Selecione em quantas páginas A4 você deseja dividir a imagem (ex: 4, 9, 16 folhas).
3. **Ajuste de Margens:** Defina uma margem de "sobreposição" (overlap) para facilitar a colagem das folhas após a impressão.
4. **Preview em Tempo Real:** Veja como o pôster ficará montado e inspecione cada folha individualmente no carrossel.
5. **Gere o PDF:** Clique em baixar e receba um arquivo PDF em alta resolução (300 DPI), pronto para imprimir.

## 🚀 Tecnologias Utilizadas
- **React + TypeScript:** Interface rápida e segura.
- **Tailwind CSS:** Design moderno e responsivo com o tema "Artistic Flair".
- **jsPDF:** Geração de documentos PDF diretamente no navegador.
- **Canvas API:** Processamento de imagem de alta performance para garantir nitidez máxima.

## 🛠️ Qualidade de Impressão
O PosterSlice garante que a qualidade da sua imagem original seja preservada. Durante a exportação, o sistema utiliza um algoritmo de re-amostragem em 300 DPI, garantindo que o resultado final no papel seja nítido e profissional, ideal para grandes formatos.
